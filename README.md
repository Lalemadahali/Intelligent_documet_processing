# Intelligent_documet_processing
Databricks &amp; Document AI: PySpark, SQL, Databricks Genie, catalogs, workspaces, document parsing, and document-based question answering.
Document Question Answering with Databricks

This project explores how to process documents and ask questions about their contents using Databricks. I implemented the complete workflow by following a hands-on tutorial, using PySpark, SQL, and Databricks Genie.

The workflow includes parsing documents, processing their contents with PySpark and SQL, and organizing the resulting data in Databricks catalogs. I developed and ran the code within a Databricks workspace and used Genie to explore the prepared data through natural-language questions.

Through this project, I gained practical experience with document processing, data organization, and question answering in Databricks. It also strengthened my understanding of how notebooks, catalogs, SQL, and Genie work together to support data exploration.

To reproduce the project, import the notebooks into a Databricks workspace, provide the source documents, and update the catalog, schema, and file paths to match your environment. Run the notebooks in workflow order, then configure a Genie space with the prepared tables to explore the data. The repository contains the exported code; the required Databricks resources and Genie configuration must be set up separately.
